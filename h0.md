## H0

## a) Compile a simple program. Analyze the binary.

Tein tehtävän Debian-virtuaalikoneessa. Kirjoitin ohjelman, käänsin sen GCC:llä ja analysoin ohjelmatiedoston file-komennolla. Lopuksi suoritin ohjelman varmistaakseni toimivuuden.

- Avasin nano-editorin ja loin uuden tiedoston:
```
nano h0.c
```

- Kirjoitin sisälle Hello world! –ohjelman:

<img width="192" height="13" alt="Komennosta kuva terminaalissa." src="https://github.com/user-attachments/assets/f083fc94-5cde-491f-a62a-b7323124bf0c" />

```
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

- Ohjelma hyödyntää stdio.h-kirjastoa, joka sisältää printf()-funktion. Ilman koodin alkua ohjelma ei kääntyisi, koska käännös ei tunnistaisi tulostusfunktiota.
