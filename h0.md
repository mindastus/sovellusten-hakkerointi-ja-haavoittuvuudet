## H0

## a) Compile a simple program. Analyze the binary.

Tein tehtävän Debian-virtuaalikoneessa. Kirjoitin ohjelman, käänsin sen GCC:llä ja analysoin ohjelmatiedoston file-komennolla. Lopuksi suoritin ohjelman varmistaakseni toimivuuden.

- Avasin nano-editorin ja loin uuden tiedoston:
```
nano h0.c
```
<img width="192" height="13" alt="Komennosta kuva terminaalissa." src="https://github.com/user-attachments/assets/f083fc94-5cde-491f-a62a-b7323124bf0c" />

##

Kirjoitin sisälle Hello world! –ohjelman:

<img width="251" height="133" alt="Terminaalissa hei maailman koodi." src="https://github.com/user-attachments/assets/bcdaaf77-a533-489e-a899-f8761c87704d" />

```
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

- Ohjelma hyödyntää stdio.h-kirjastoa, joka sisältää printf()-funktion. Ilman koodin alkua ohjelma ei kääntyisi, koska käännös ei tunnistaisi funktiota.  `(Programiz s.a.)`

##

Käänsin ohjelman komennolla:

<img width="386" height="56" alt="Terminaalissa oleva Gcc työkalu." src="https://github.com/user-attachments/assets/f4d75920-8a58-43c0-b578-1be5221c754f" />
<img width="202" height="22" alt="Terminaalissa gcc käyttö" src="https://github.com/user-attachments/assets/7906dda2-6256-4bb3-b756-b573db0f4c27" />

```
gcc h0.c
```
- GCC loi kotihakemistoon tiedoston nimeltä a.out, joka on Linuxin oletusnimi käännetylle ohjelmalle. `(TheLinuxCode 2023)`
