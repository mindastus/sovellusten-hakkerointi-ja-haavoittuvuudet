## x) Lue/katso ja tiivistä

**OWASP: OWASP Top 10: A01 Broken Access Control**
- Broken Access Control on haavoittuvuus, jossa sovellus ei valvo käyttäjien oikeuksia oikein, jolloin käyttäjä voi päästä käsiksi tietoihin tai toimintoihin, joihin hänellä ei kuulu olla pääsyä.

**Karvinen 2023: Find Hidden Web Directories - Fuzz URLs with ffuf**
- FFuf on verkkofuzzaukseen tarkoitettu työkalu, jolla voidaan tunnistaa piilotettuja URL-polkuja ja hakemistoja sanalistojen avulla. Pelkkä HTTP-statuskoodien tarkastelu ei aina riitä, sillä sovellus voi palauttaa saman vastauksen kaikille pyynnöille. Tällöin tuloksia täytyy suodattaa esimerkiksi vastauksen koon (-fs), sanamäärän (-fw) tai rivimäärän (-fl) perusteella.

**PortSwigger: Access control vulnerabilities and privilege escalation**
- Puutteellinen käyttöoikeuksien hallinta tarkoittaa haavoittuvuutta, jossa käyttäjä pystyy käyttämään toimintoja tai tietoja, joihin hänellä ei pitäisi olla oikeutta, esimerkiksi nostamalla omia käyttöoikeuksiaan tai käsittelemällä muiden käyttäjien tietoja.

**Vapaaehtoinen: PortSwigger 2020: What is SQL injection? - Web Security Academy (about 10 min video)**
- SQL Injection syntyy, kun käyttäjän syöte pääsee muuttamaan SQL-kyselyn rakennetta, ja tehokkain suoja sitä vastaan on parametrisoitujen kyselyjen käyttö.
