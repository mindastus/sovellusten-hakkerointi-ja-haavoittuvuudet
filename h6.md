## 🔍 5. **Sovellusten etsiminen**

Tutki hakemistoja:

```
/bin
/sbin
/usr/bin
/usr/sbin
/etc/init.d
/etc/config
```

Etsi:

- epäilyttävät binäärit  
- debug‑työkalut  
- kovakoodatut IP‑osoitteet  
- skriptit jotka käynnistyvät automaattisesti  
- palvelut jotka kuuntelevat verkossa

Hyödyllisiä komentoja:

```bash
strings <tiedosto> | less
grep -R "admin" .
grep -R "password" .
grep -R "telnet" .
grep -R "dropbear" .
```

## 🔑 6. **Root‑salasanan analysointi**

Etsi passwd ja shadow:

```
/etc/passwd
/etc/shadow
```

Jos shadow sisältää hashin:

```bash
john --wordlist=/usr/share/wordlists/rockyou.txt shadowfile
```

Jos hash on tyhjä → root‑login voi olla estetty.  
Jos hash on sama kuin tunnetuissa Tapo‑haavoittuvuuksissa → raportoi.
